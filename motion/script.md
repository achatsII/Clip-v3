# Script — film de présentation de Clip (~72 s, voix Aoede qc)

| # | Voix | Ce qu'on voit |
|---|---|---|
| v01 | Jacques connaît sa machine mieux que personne. | Clip IA : Jacques explique à sa CNC, la main sur les rails ; pastille de verre « Jacques · machiniste ». |
| v02 | Dans un an, il prend sa retraite. | Gros plan, ses mains gantées brossent les rails ; une pastille « Retraite » se pose. |
| v03 | Et d'ici 2030, de vingt à trente pour cent des technologues partiront aussi. | L'usine en plan large (clip) ; « 20 à 30 % » court à l'écran, la barre jusqu'à 2030 se remplit en rouge. |
| v04 | Leur savoir-faire n'est écrit nulle part. | Le vieux cartable aux pages jaunies ; l'image se referme en une carte. |
| — | (silence, la musique entre) | Le trait du logo Clip se dessine, le logo apparaît. |
| v05 | Voici Clip. | Logo et nom, sur le temps fort. |
| v06 | Filmez l'expert pendant qu'il explique. Clip enregistre tout, sur le téléphone. | Mélanie filme Jacques ; on plonge dans le téléphone : la caméra de Clip, « 02:14 » en rouge. |
| v07 | Ajoutez des photos, une note vocale, ou vos vieilles procédures en PDF et en Word. | L'écran « Nouvelle instruction » : chaque carte (photo, note vocale, PDF) arrive sur son mot. |
| v08 | Puis, d'un seul bouton, l'IA rédige l'instruction de travail. | Le curseur clique « Générer l'instruction » ; « L'IA rédige votre instruction », les étapes se cochent. |
| v09 | Une action par étape, le bon extrait vidéo, les mises en garde au bon moment. | Les 5 étapes tombent une à une ; l'extrait vidéo joue ; la mise en garde « Attention » éclate sur « mises en garde ». |
| v10 | Retouchez d'un mot. Annotez d'un clic. Traduisez en quelques secondes. | Coupes rapides : l'assistant réécrit l'étape ; l'IA encercle le bouton vert ; l'étape passe en espagnol, chinois, arabe. |
| v11 | Et vos vieilles instructions? Clip les modernise par dizaines. | Le cartable, puis 40 PDF déposés d'un coup : « 40 sur 40 terminés ». |
| v12 | Faites-la approuver, puis déployez-la au poste, sur une tablette ou par code QR, sans compte. | Clic « Approuver et publier », confettis ; Kevin à la tablette du poste, le code QR de la machine ; on plonge dans la tablette. |
| v13 | L'opérateur suit chaque étape, l'écoute à voix haute, et signale ce qui n'est pas clair. | Dans la tablette : « Suivant », « Écouter », « Pas clair ? » touchés chacun sur son mot. |
| v14 | Et tout s'exporte en PDF, d'un clic. | La page PDF de l'instruction sort de l'écran. |
| v15 | Clip. Le savoir-faire de vos experts, au poste, en quelques minutes. | Logo, la promesse en trois temps. |
| v16 | (appel à l'action, à confirmer) | Carte finale avec l'appel à l'action ; tenue ≥ 1,5 s. |

≈ 165 mots, 16 phrases : ≈ 72 s avec les pauses. Coupes sur le tempo de la musique, effets sonores
sur chaque clic, chaque carte, chaque coche (comme K2 V2).
